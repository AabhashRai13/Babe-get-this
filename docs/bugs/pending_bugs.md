4) Voice review sheet — swipe-delete cascade. Swiping to delete the first item also deletes the second; after that the third (now last remaining) item can't be swipe-deleted at all. File: `core/voice/ui/reviewing/ReviewingMode.kt`.
   **Hint to self:** `LazyColumn` calls `itemsIndexed(drafts) { ... }` with no `key` param. Inside each row, two pieces of state are `remember`d: `var visible by remember { mutableStateOf(false) }` (the stagger flag) and `dismissState` inside `SwipeableCard`. When the list shrinks and survivors shift to lower positions, the *slot* keeps its stale `remember`d state — so the slot that just hosted a mid-swipe row now hosts the survivor, still in dismissed-state. That explains both the cascade and the unswipeable last item. Fix direction: give each draft a stable id and pass `key = { _, d -> d.id }` to `itemsIndexed` so per-row state follows the draft, not the slot.
